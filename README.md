# University Quiz Bot — HOKAS

بوت اختبارات جامعي لتيليجرام مع لوحة إدارة ويب، قاعدة SQLite، وربط OpenAI لتوليد الأسئلة والمساعدة التعليمية.

## المتطلبات
- Python 3.11.9 (محدد في `runtime.txt`).
- Bot Token من @BotFather.
- OpenAI API Key مع تفعيل الفوترة/الرصيد وصلاحية النموذج المحدد.
- متغيرات البيئة في `.env.example`.
- OCR للصور وملفات PDF الممسوحة يتطلب تثبيت محرك Tesseract على الخادم، وليس حزمة Python فقط. أضف اللغات المطلوبة مثل `ara` و`eng` إذا كانت متاحة في نظام الاستضافة.

## إعداد HOKAS
1. ارفع محتويات ملف ZIP بعد فك الضغط داخل مجلد المشروع.
2. ثبّت المتطلبات من `requirements.txt`.
3. أضف متغيرات البيئة من `.env.example` في إعدادات المشروع، مع وضع القيم الحقيقية وعدم مشاركة المفاتيح.
4. اجعل أمر التشغيل `python run.py`.
5. فعّل خدمة ويب/منفذ HTTP على المنصة، ثم افتح رابط الخدمة لعرض لوحة الإدارة.
6. اجعل `DATABASE_PATH` و`UPLOAD_FOLDER` على مساحة تخزين دائمة؛ وإلا قد تفقد البيانات والملفات عند إعادة تشغيل الحاوية.

## المتغيرات الأساسية
- `BOT_TOKEN`: توكن تيليجرام.
- `OPENAI_API_KEY`: مفتاح OpenAI.
- `OPENAI_MODEL`: النموذج، الافتراضي `gpt-4o-mini`.
- `ADMIN_IDS`: معرفات تيليجرام للمشرفين، مفصولة بفواصل.
- `DASHBOARD_USERNAME` و`DASHBOARD_PASSWORD`: دخول لوحة الإدارة.
- `FLASK_SECRET_KEY`: قيمة سرية طويلة وعشوائية.
- `COOKIE_SECURE=true` عند استخدام HTTPS.
- `PORT`: منفذ الويب الذي تحدده HOKAS.

## تشغيل محلي
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# عدّل القيم داخل .env
python run.py
```

## وظائف البوت
- `/start`: القائمة الرئيسية.
- `/quizzes`: عرض الاختبارات المنشورة.
- `/quiz 1`: بدء اختبار محدد.
- `/newquiz`: إنشاء اختبار يدويًا للمشرف.
- `/ask سؤالك`: المساعد التعليمي عبر OpenAI.
- `/cancel`: إلغاء إنشاء الاختبار أو الاختبار الجاري.
- يدعم الاختبار مؤقتًا لكل سؤال حسب `question_seconds` (الافتراضي 30 ثانية).
- يمكن للمشرف إرسال ملف مدعوم إلى البوت؛ يستخرج النص ويولّد 5 أسئلة، ويحفظها كمسودة غير منشورة.

## إنشاء اختبار من لوحة الإدارة
1. سجّل الدخول باستخدام `DASHBOARD_USERNAME` و`DASHBOARD_PASSWORD`.
2. ارفع ملفًا من الصيغ المدعومة.
3. من قسم توليد الاختبارات، اختر عدد الأسئلة واضغط «توليد أسئلة».
4. افتح «مراجعة الأسئلة» وتحقق من السؤال والخيارات والإجابة الصحيحة والشرح.
5. اضغط «اعتماد الاختبار ونشره» ليظهر للطلاب في قائمة الاختبارات.

## صيغ الملفات المدعومة
PDF, DOCX, PPTX, XLSX, XLSM, CSV, TXT, PNG, JPG, JPEG, WEBP. قد تحتاج ملفات الصور وPDF الممسوحة إلى Tesseract OCR. ملفات PDF النصية وملفات Word/PowerPoint/Excel والجداول تُستخرج برمجيًا.

## ملاحظات تشغيل مهمة
- لا يمكن ضمان نجاح اتصال OpenAI قبل وضع مفتاح صالح في HOKAS؛ هذا المشروع لا يحتوي مفتاحًا خاصًا.
- أخطاء المفتاح (401) وحد الاستخدام/الرصيد (429) واسم النموذج (400/404) تظهر برسائل منفصلة في البوت، مع تفاصيل تقنية في سجل الخادم.
- لوحة الإدارة تتضمن الإحصاءات، عرض الطلاب والاختبارات والمواد، رفع المواد، توليد المسودات، مراجعتها، نشرها وحذفها، والتحكم بإظهار المتصدرين.
- قاعدة البيانات SQLite مناسبة كبداية. استخدم تخزينًا دائمًا، وفكّر في PostgreSQL إذا كانت المنصة تشغّل أكثر من نسخة أو كان الاستخدام كثيفًا.
- التشغيل يجمع Flask وTelegram polling في عملية واحدة؛ يجب أن تسمح HOKAS بعملية طويلة العمر مع منفذ ويب. إذا كانت HOKAS تفصل خدمات الويب والعمال، فشغّل البوت والويب كخدمتين منفصلتين.
- لم تتم تجربة نشر فعلي على حساب HOKAS أو اتصال OpenAI حقيقي في بيئة المستخدم؛ يلزم اختبارهما بعد إدخال مفاتيح البيئة على المنصة.
